# 🍗 REY-VEN — Carta digital y pedidos

Prototipo web para **Rey Ven**, un local de comida rápida en Lima: carta digital, carrito y seguimiento de pedidos en tres vistas.

- **Cliente**: landing, carta por categorías y carrito de compra.
- **Cocina**: cola de pedidos entrantes y cambio de estado.
- **Administración**: gestión del menú y de los pedidos.

Los datos del menú y de los pedidos son simulados (`src/data/`); el estado se maneja con React Context (autenticación, carrito y pedidos).

## Stack

React 18 · TypeScript · Vite · Tailwind CSS

## Ejecutar

```bash
npm install
npm run dev
```
